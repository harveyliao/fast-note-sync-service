# Fast Note Sync Service - NixOS

Nix package and NixOS module for self-hosting
[Fast Note Sync Service](https://github.com/haierkeys/fast-note-sync-service),
a real-time Obsidian note sync server.

## Setup

### 1. Build the package

```bash
nix build ./nix#fast-note-sync-service
./result/bin/fast-note-sync-service --help
```

### 2. Add to your NixOS flake

In your system `flake.nix`:

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    fns.url = "github:haierkeys/fast-note-sync-service?dir=nix";
  };

  outputs = { self, nixpkgs, fns, ... }: {
    nixosConfigurations.your-hostname = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        fns.nixosModules.default
        ./configuration.nix
      ];
    };
  };
}
```

### 3. Enable in configuration.nix

Minimal:
```nix
{
  services.fast-note-sync-service.enable = true;
}
```

Full example with custom settings:
```nix
{
  services.fast-note-sync-service = {
    enable = true;
    port = 9000;
    openFirewall = true;  # opens port 9000

    settings = {
      # Override any config.yaml field here
      security = {
        auth-token-key = "your-secret-key-generate-with-openssl-rand-base64-32";
      };
      user = {
        register-is-enable = false;  # disable after creating your account
        admin-uid = 1;               # set to your user's UID after first login
      };
    };
  };
}
```

The module generates a complete YAML configuration file and starts the service
with `fast-note-sync-service run -c <generated-config>`.

### 4. Rebuild

```bash
sudo nixos-rebuild switch --flake /path/to/your/flake
```

### 5. First use

1. Open `http://<server-ip>:9000/webgui` in your browser
2. Register an account (registration is enabled by default)
3. Click "Copy API Configuration" in the web panel
4. In Obsidian, install the Fast Note Sync plugin (via BRAT or manual)
5. In plugin settings, paste the API configuration

## Obsidian Plugin Installation

The plugin isn't in the official store yet. Install via:

- **BRAT** (recommended, supports mobile): Install the BRAT plugin, add
  `https://github.com/haierkeys/obsidian-fast-note-sync`
- **Manual**: Download from
  [releases](https://github.com/haierkeys/obsidian-fast-note-sync/releases),
  extract to `.obsidian/plugins/obsidian-fast-note-sync/`

## Configuration Reference

All fields from [config/config.yaml](https://github.com/haierkeys/fast-note-sync-service/blob/master/config/config.yaml)
can be set via `services.fast-note-sync-service.settings`. The NixOS module
provides sensible defaults; any value you set in `settings` overrides the default.

The generated config is a complete standalone config.yaml — the service reads it
via the `-c` flag (no merging with the embedded default).

## Package Notes

- The package builds release `2.13.6`, matching the upstream Git tag name.
- `go.mod` requires Go `1.26.2`, so the flake pins `nixos-unstable`.
- CGO is disabled.
- The binary embeds `frontend/`, `docs/`, and `config/config.yaml` from the
  fetched source tree.
- Checks are disabled for the package because the upstream release test suite
  currently fails in `internal/routers/api_router` during Nix builds. This does
  not affect the produced service binary.

## Data Layout

```
/var/lib/fast-note-sync/          # dataDir
|-- config/                       # unused when config is generated by Nix
`-- storage/
    |-- database/db.sqlite3       # SQLite database
    |-- uploads/                  # attachment storage
    |-- temp/                     # temporary files
    `-- logs/log.log              # service logs
```

State directories are created with `systemd.tmpfiles.rules` and owned by the
`fast-note-sync` system user.

## Security Notes

- Change `security.auth-token-key` from the default after first setup
- Set `user.register-is-enable = false` after creating your account
- The systemd service runs with hardening (ProtectSystem, NoNewPrivileges, etc.)
- For internet access, put behind a reverse proxy (nginx/caddy) with TLS
